v1.0.0
======

New Modules
-----------

- redhat.ai.completion - Interact with deployed AI model.
- redhat.ai.ilab_config - Edit existing InstructLab configuration.
- redhat.ai.ilab_init - Create initial InstructLab configuration.
- redhat.ai.ilab_model_download - Download InstructLab AI model.

New Playbooks
-------------

- redhat.ai.ilab - A playbook to configures a VM with Red Hat AI preinstalled to server a specified AI model.

New Roles
---------

- redhat.ai.ilab_serve - A role to setup systemd service for serving AI model.
